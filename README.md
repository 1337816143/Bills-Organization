# Bills Organization

一个本地优先（local-first）的个人账单整理网站，用于统一管理微信、支付宝和银行卡流水，并针对跨平台绑卡支付进行去重。

## 当前功能

- 首次自动载入本项目从原 HTML 报告迁移的 580 条历史流水，并保留每条交易的完整原始字段。
- 多格式增量导入：CSV / TXT、XLS / XLSX、PDF、JSON、HTML。
- 已适配：微信支付、支付宝、中国建设银行、中国农业银行；其他表格尝试按通用字段自动识别。
- 自动提取账单明细与可识别的汇总信息。
- 相同账单重复导入时按稳定指纹跳过已有记录，仅增加新明细。
- 跨平台重复检测：优先保留微信 / 支付宝详细记录，确认的银行卡镜像标记为 `confirmed-drop`；不确定匹配仅标记为 `suspected`，不会自动剔除。
- 每笔流水可以手动归类为：旅游支出、旅游期间非旅游支出、其他 / 非旅游、未判断。
- 自动计算：去重后支出、收入、净支出、纯旅游支出、旅游期间总支出。
- 多版本导出：仅支出、仅收入、收支汇总、旅游支出、旅游期间总支出、指定人工分类。
- 多格式导出：XLSX、CSV、JSON、独立 HTML 报告。
- 整库 JSON 备份 / 恢复。
- 数据保存在浏览器 IndexedDB 中，不设置后端，不上传账单文件。

## 导入规则

浏览器端使用 SheetJS 解析 XLS / XLSX，使用 PDF.js 解析 PDF。支付宝 GBK/GB18030 CSV 会自动尝试编码识别。

导入后先做同来源稳定指纹去重，再做支付平台与银行卡之间的跨平台匹配。自动匹配会综合日期、金额、支付渠道、银行卡尾号、时间差和商户文本；证据不足的记录只标“疑似重复”。
